A calm digital space made with sound

GrainMeditate is a browser instrument for meditation. It uses slow sound, simple controls and moving light to help the user relax.

01 / SCENARIO

Design Scenario

GrainMeditate is a meditation tool using sound. Its main goal is to help the user feel calm and focused.

The user does not need music skills. The sound should change slowly and should not feel sudden, loud or stressful.

The project uses granular synthesis. This technique cuts a recording into very small sound pieces and plays them in different ways. It can create soft and dreamy textures.

02 / OVERVIEW

Project Overview

Project Idea

GrainMeditate uses nature sounds and singing bowl sounds. The user moves one main Flow slider to slowly change the sound.

Purpose

The sound can stay in the background while the user meditates, studies or rests.

Value

The interface is simple and open to everyone. It uses clear words, large controls and no difficult music settings.

03 / FRAMING

Project Framing

Included

  • Web Audio API
  • Granular synthesis
  • Nature and singing bowl sounds
  • Mouse and touch control
  • Soft animation and glowing visuals
  • Simple sound settings

Not Included

  • Fast beats
  • Loud or harsh sounds
  • Piano keyboard controls
  • Too many buttons
  • Complex music settings
  • Scores or competition

04 / RESEARCH

Interaction Design Analysis

01

Ambient Chaos

Ambient Chaos uses one simple control. It shows that one slider can still create many sound changes.

What I learned: My project will also use one main Flow slider.

02

Patatap

Patatap gives sound and visual feedback immediately when the user presses a key.

What I learned: My project should also show clear visual feedback.

03

Tone Matrix

Tone Matrix uses simple squares that work as controls and also show the current sound state.

What I learned: My control should also show the sound level.

04

Chrome Music Lab Spectrogram

The Spectrogram shows sound as moving colour. This helps the user see the audio.

What I learned: My project will use a moving light circle.
