1. Design Scenario

GrainMeditate is a browser-based audio instrument for meditation. Its purpose is to help the user feel calm and focused.

The sound should be soft and slow. The user does not need music knowledge or performance skills.

The project uses granular synthesis. This technique divides a sound into small pieces and uses them to create a new sound texture.

2. Project Overview

Project Idea

GrainMeditate uses nature recordings and singing bowl sounds. The user can change the sound with simple controls.

Purpose and Value

The project can be used during meditation, study or rest. The interface is simple so that anyone can use it.

3. Project Framing

Included

  • Web browser
  • Web Audio API
  • Granular synthesis
  • Nature recordings
  • Simple controls
  • Slow animation

Not Included

  • Fast beats
  • Harsh sounds
  • Piano keyboard
  • Complex settings
  • Too many buttons
  • Competition

4. Interaction Design Analysis

Ambient Chaos

Ambient Chaos uses one main slider. It showed me that one control can still make different sound changes.

Patatap

Patatap gives sound and visual feedback immediately. My instrument should also give clear feedback.

Tone Matrix

Tone Matrix uses controls that also show the current sound state. My sound circle will also show when sound is active.

Chrome Music Lab Spectrogram

The Spectrogram shows sound as moving colour. This influenced the simple visual feedback in my project.
