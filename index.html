1. Design Scenario Analysis

My chosen scenario is collaborative and social creation. I understand this scenario as designing an instrument that helps people make music together.

The project should allow users to record short sounds, place them into loops and combine them with sounds made by other people.

The main values of the project are accessibility, creativity, communication and shared ownership. Users should not need professional music skills.

2. Project Overview

Project Name

Loop Together

Synopsis

Loop Together is a simple browser-based audio instrument for the general public. Users can record a short sound with a microphone or choose a sample. The sound will repeat inside a shared music loop.

Different users can add rhythm, voice and background sounds. Together, these sounds create one group composition.

Purpose

The purpose is to make collaborative music creation simple and enjoyable. The interface will use large buttons, clear colours and simple instructions.

3. Project Framing

The project is designed as a playful music space instead of professional music production software.

Included

  • Microphone recording
  • Built-in audio samples
  • Four sound layers
  • Loop playback
  • Volume and mute controls
  • Colour feedback
  • Simple group sessions

Not Included

  • Professional mixing tools
  • Music notation
  • Complex editing timelines
  • Competitive scoring
  • Public follower systems
  • AI-generated music

Technology

HTML will create the page structure. CSS will control the layout and visual style. JavaScript will control buttons and interaction. The final instrument could use the Web Audio API and microphone access.

4. Interaction Design Analysis

Chrome Music Lab: Song Maker

Song Maker uses a colourful grid to show rhythm and melody. It is easy to understand because users can see where sounds are placed.

This inspired me to use a simple beat grid and colours to show each sound.

Visit Song Maker

Incredibox

Incredibox allows users to drag sound icons onto animated characters. The characters make music creation feel friendly and playful.

This inspired me to give each user a colour and clear visual identity.

Visit Incredibox

Ableton Learning Music

Ableton Learning Music teaches music through short interactive activities. Users learn by trying actions and hearing the result immediately.

This inspired me to use short instructions inside the instrument.

Visit Ableton Learning Music

Patatap

Patatap creates sound and animation when users press keyboard buttons. The feedback is immediate and encourages experimentation.

This inspired me to connect every sound with a simple visual animation.

Visit Patatap

5. Proposed System

1. Join

The user opens a shared link and enters a name.

2. Record

The user records a short sound or selects a sample.

3. Loop

The sound repeats with the shared beat.

4. Collaborate

Other users add sounds to create one composition.

Main Interface Areas

  • Session name and participant number
  • Play and stop button
  • Eight-beat loop display
  • Four sound layers
  • Record button
  • Volume, mute and delete buttons
