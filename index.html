1. Design Scenario

GrainMeditate is a browser audio instrument for meditation. The main goal is to help the user feel calm and relaxed.

The instrument should be easy to use. The user does not need music skills. The sounds should change slowly and should not be too loud or sudden.

The project uses granular synthesis. This technique cuts a sound recording into many small pieces and plays them in different ways. It can create soft and dreamy sounds.

2. Project Overview

Project Idea

GrainMeditate is a simple web instrument using nature sounds and singing bowl sounds. The user can move a main Flow slider to change the sound.

Purpose

The project is made for meditation and quiet listening. The user can leave the sound playing in the background or slowly change it.

Value

The design is simple and open to everyone. It uses soft colours, large controls and easy words. The user does not need to understand music theory.

3. Project Framing

Included

  • Web browser and Web Audio API
  • Granular synthesis
  • Nature and singing bowl sounds
  • Mouse and touch controls
  • Soft colours and slow animation
  • Simple sound controls

Not Included

  • Fast beats
  • Loud or harsh sounds
  • Piano keyboard controls
  • Too many buttons
  • Complex music settings
  • Scores or competition

4. Interaction Design Analysis

4.1 Ambient Chaos

Ambient Chaos has a very simple interface with one main control. It shows that one slider can control many sound changes.

What I learned: My project will also use one main Flow slider.

4.2 Patatap

Patatap gives sound and visual feedback when the user presses a key. It is easy to understand because the response happens straight away.

What I learned: GrainMeditate should also give clear feedback, but the movement should be slower and calmer.

4.3 Tone Matrix

Tone Matrix uses simple squares. The squares are controls and also show which sounds are active.

What I learned: The main control in my project should also show the current sound level with light and movement.

4.4 Chrome Music Lab Spectrogram

The Spectrogram shows sound as moving colour. This helps the user see the sound.

What I learned: My project will use a slowly moving circle to show that the sound is active.
