1. Design Scenario

GrainMeditate is a browser audio instrument for meditation. It helps the user feel calm and focused.

The sound should be soft and slow. The user does not need music knowledge.

The project uses granular synthesis. It cuts a recording into small pieces and creates a new sound texture.

2. Project Overview

GrainMeditate uses nature and singing bowl sounds. The user changes the sound with simple sliders.

The project is made for meditation, study and rest.

3. Project Framing

Included

  • Web Audio API
  • Granular synthesis
  • Nature sounds
  • Simple controls
  • Slow animation

Not Included

  • Fast beats
  • Loud sounds
  • Music keyboard
  • Too many buttons
  • Competition

4. Interaction Design Analysis

Ambient Chaos

It uses one main slider. This showed me that one control can make many sound changes.

Patatap

It gives sound and visual feedback quickly. My project will also show a clear response.

Tone Matrix

Its controls also show the sound state. My circle will change when sound is playing.

Chrome Music Lab Spectrogram

It shows sound as moving colour. My project also uses a moving circle.
