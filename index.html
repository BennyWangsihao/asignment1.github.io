1. Design Scenario

GrainMeditate is a browser-based audio instrument for meditation. Its main purpose is to help the user feel calm, focused and comfortable. It is not designed as a normal musical instrument that requires skill.

The user should be able to open the page, start the sound and relax. The controls should be easy to understand. The sound should change slowly so the experience does not become stressful or confusing.

The project responds to the scenario by using a soft visual style, simple interaction and quiet sound. It should support meditation, study breaks and rest.

The project also values accessibility. A user should not need music theory or audio production knowledge. Large buttons, clear text and simple sliders make the instrument easier to use.

2. Project Overview

Project Idea

GrainMeditate uses nature recordings, singing bowl sounds and soft electronic tones. The final instrument will use granular synthesis to divide recordings into small sound pieces called grains.

These grains can be played at different speeds, pitches and positions. This can create a slow and dreamy sound texture that changes over time.

User Experience

The user starts the sound with one button. A Flow slider changes the speed and pitch of the sound. A Volume slider controls how loud it is. A moving circle shows when the instrument is active.

The interface does not ask the user to make a song. Instead, the user gently changes an existing sound environment. This makes the experience less like performing and more like shaping a calm atmosphere.

Purpose and Worth

The purpose is to create a simple sound space for relaxation. The main values are calmness, ease of use, safety and openness. The design should avoid sudden sounds, complex menus and pressure.

3. Project Framing

Project framing explains what the project will include and what it will leave out. This helps keep the design focused and realistic.

Included

  • Web browser platform
  • HTML, CSS and JavaScript
  • Web Audio API
  • Granular synthesis
  • Nature and singing bowl recordings
  • Simple sliders and buttons
  • Slow visual animation
  • Mouse and touch interaction

Not Included

  • Fast beats and dance rhythms
  • Harsh distortion
  • Piano keyboard controls
  • Complex audio editing
  • Too many menus
  • User accounts
  • Scores or competition
  • Professional studio tools

Visual Style

The website uses a light background, dark text and blue details. This makes the information easy to read. Rounded shapes and slow movement give the project a gentle and quiet feeling.

Sound Style

The sound should be soft, warm and continuous. It should not suddenly become loud. The final version will use recorded sounds, while this prototype uses browser-generated tones to test the interaction.

4. Interaction Design Analysis

Ambient Chaos

Ambient Chaos uses one main slider. The page is simple, but the sound can still change in different ways.

What I learned: GrainMeditate can also use one main control to change several sound qualities.

Patatap

Patatap gives sound and visual feedback immediately. The user can understand that an action has worked without reading instructions.

What I learned: GrainMeditate should also give clear visual feedback when sound starts or changes.

Tone Matrix

Tone Matrix uses controls that also show the current state. Active squares light up, so the user can see what is playing.

What I learned: The sound circle in my project should move when audio is active.

Chrome Music Lab Spectrogram

The Spectrogram shows sound as moving colour. This makes invisible audio easier to understand and more interesting to watch.

What I learned: GrainMeditate should connect sound with a simple visual movement.

5. Simple System Design

Input

The user presses buttons and moves sliders.

Audio

JavaScript and the Web Audio API create and change the sound.

Visual Feedback

The circle moves when the sound is playing.

Output

The user hears a soft tone through speakers or headphones.
